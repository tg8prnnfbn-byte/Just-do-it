# Трекер трендів YouTube

Показує, які свіжі відео у твоїй ніші найшвидше набирають перегляди.

## Як працює
1. Для кожного запиту з `config.json` шукає відео за останні `days` днів (сортування за переглядами).
2. Якщо `popular_chart: true`, додає чарт популярного в регіоні `region`.
3. Рахує **перегляди за годину** з моменту публікації та **залученість** ((лайки + коментарі) / перегляди).
4. Зберігає знімок у `data/snapshot-*.json`. На наступному запуску порівнює з попереднім знімком
   і показує **приріст за годину**: це найточніший сигнал того, що набирає оберти саме зараз.
5. Пише звіт у `reports/latest.md`: окремо довгі відео й Shorts (до 3 хв), плюс рейтинг тем.

## Запуск
```bash
YOUTUBE_API_KEY=твій_ключ python3 trends/tracker.py          # топ-20 у кожній таблиці
YOUTUBE_API_KEY=твій_ключ python3 trends/tracker.py --top 40
```
Ключ: Google Cloud Console → увімкнути **YouTube Data API v3** → Credentials → API key.

## Квота
Безкоштовно 10 000 одиниць на день. Один пошук коштує 100, тож 5 запитів ≈ 510 одиниць за запуск,
тобто до ~19 запусків на день. Найкраще запускати 2–4 рази на день.

## Налаштування
Редагуй `config.json`: запити (`queries`), регіон, мову, кількість днів і результатів на запит.

Тести: `cd trends && python3 -m unittest test_tracker`
